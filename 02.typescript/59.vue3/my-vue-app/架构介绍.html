1 项目概览 Overview

这是由 npm create vue 脚手架生成的标准模板：一个最小可运行的 Vue 3 单页应用（SPA），采用单文件组件（SFC）+ <script setup> 语法，TypeScript 做类型检查，Vite 做开发服务器与打包。

维度选型说明
UI 框架Vue 3.5Composition API + 响应式系统
语言TypeScript 6vue-tsc 对 .vue 做类型检查
构建工具Vite 8开发态 ESM + HMR，生产态 Rollup 打包
组件风格<script setup> SFC模板/逻辑/样式三段合一
入口index.html → main.ts挂载到 #app

2 目录结构 File Structure

绿色标注的是真正承载应用逻辑的文件，其余多为配置。

my-vue-app/ ├── index.html # 唯一 HTML 入口，挂载点 <div id="app"> ├── package.json # 依赖与脚本：dev / build / preview ├── vite.config.ts # Vite 配置，注册 @vitejs/plugin-vue ├── tsconfig.json # TS 根配置（references 引用下面两个） ├── tsconfig.app.json # 应用代码的 TS 配置（src/**） ├── tsconfig.node.json # 构建脚本(vite.config.ts)的 TS 配置 ├── public/ # 原样拷贝的静态资源（不经打包） │ ├── favicon.svg │ └── icons.svg # 通过 <use href="/icons.svg#..."> 引用 └── src/ # 源码目录 ├── main.ts # JS 入口：createApp(App).mount('#app') ├── App.vue # 根组件 ├── components/ │ └── HelloWorld.vue # 示例子组件（计数器 + 链接卡片） ├── assets/ # 经打包的资源（import 引用，带 hash） │ ├── hero.png │ ├── vue.svg │ └── vite.svg ├── style.css # 全局样式（main.ts 中 import） └── shims-vue.d.ts # 为 *.svg/*.png 等声明模块类型
public/ 与 assets/ 的区别： public/ 里的文件以绝对路径 /icons.svg 直接引用，构建时原样拷贝； src/assets/ 里的文件通过 import 引入，会被 Vite 处理、加内容 hash 并优化。

4 启动与挂载流程 Bootstrap & Mount Flow

浏览器从加载脚本到首屏渲染的时序。

sequenceDiagram
    autonumber
    participant B as 浏览器
    participant H as index.html
    participant M as main.ts
    participant V as Vue 运行时
    participant A as App.vue
    participant C as HelloWorld.vue

    B->>H: 1. 加载 HTML，发现 #app 占位节点
    H->>M: 2. <script type="module"> 加载 main.ts
    M->>M: 3. import './style.css' 注入全局样式
    M->>V: 4. createApp(App) 创建应用实例
    M->>V: 5. .mount('#app')
    V->>A: 6. 渲染根组件 App
    A->>C: 7. 渲染 <HelloWorld />
    C-->>V: 8. setup() 执行，建立 count 响应式
    V-->>B: 9. 生成真实 DOM，首屏可见

入口代码 src/main.ts

import { createApp } from 'vue'
import './style.css'            // 全局样式副作用导入
import App from './App.vue'     // 根组件

createApp(App).mount('#app')  // 挂载到 index.html 的 #app

6 单文件组件解剖 SFC Anatomy

每个 .vue 文件由三个块组成。下图是一个 SFC 经编译后落到运行时的过程。

<script setup>

编译时语法糖。顶层声明的变量、import、函数会自动暴露给模板，无需 return。本项目用它声明 count 和图片 import。

<template>

声明式模板。:src 是属性绑定，@click="count++" 是事件绑定，{{ count }} 是文本插值。

7 响应式数据流 Reactivity Flow

Vue 3 的核心：ref 把值包成响应式对象，模板读取时建立依赖，值变化时自动重渲染对应 DOM。以计数器为例：

    B["模板读取 {{ count }}
收集依赖 (track)"]:::b
    C["用户点击按钮
@click="count++""]:::c
    D["count.value 改变
触发更新 (trigger)"]:::d
    E["重新执行 render
diff 虚拟 DOM"]:::e
    F["仅更新变化的 DOM 节点"]:::f

    A --> B
    C --> D --> E --> F
    B -. 建立依赖 .-> D

为什么开发态秒启动？

Vite 不打包整个应用，而是利用浏览器原生 ESM，只在请求到某个模块时即时编译它。@vitejs/plugin-vue 负责把 .vue 拆解成 JS。

类型检查与打包分离

vue-tsc -b 只做类型校验不产出代码；真正的打包交给基于 Rollup 的 vite build。这样类型错误能在构建时拦截。
