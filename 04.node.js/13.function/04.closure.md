# 04.closure.js 代码详解与闭包讲解

## 一、源码

```javascript
function createCounter() {
    let count = 0;
    return function() {
        count++;
        return count;
    };
}

const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

## 二、逐行解释

### 第 1 行
```javascript
function createCounter() {
```
定义一个「工厂函数」`createCounter`，它的作用是创建并返回一个计数器函数。

### 第 2 行
```javascript
    let count = 0;
```
在 `createCounter` 函数内部声明局部变量 `count`，初始值为 `0`。
注意：`count` 是**函数内部的局部变量**，正常情况下外部无法直接访问它。

### 第 3～6 行
```javascript
    return function() {
        count++;
        return count;
    };
```
返回一个**匿名内部函数**。这个内部函数做两件事：
- `count++`：把外层 `count` 加 1。
- `return count`：返回加 1 后的 `count`。

关键点：这个内部函数**引用了外层函数的变量 `count`**。当 `createCounter` 执行结束后，按常理它的局部变量 `count` 应该被销毁，但因为内部函数仍然引用着 `count`，所以 `count` 不会被回收——这就是**闭包**。

### 第 7 行
```javascript
}
```
`createCounter` 函数定义结束。

### 第 9 行
```javascript
const counter = createCounter();
```
调用 `createCounter()`，它返回内部那个匿名函数，并赋值给 `counter`。
此时 `counter` 就是一个闭包：它「记住」了自己诞生时所在的作用域，其中包含 `count = 0`。

### 第 10 行
```javascript
console.log(counter()); // 1
```
第一次调用 `counter()`：`count` 从 0 变成 1，返回并打印 `1`。

### 第 11 行
```javascript
console.log(counter()); // 2
```
第二次调用 `counter()`：**注意 `count` 并没有重新初始化为 0**，而是延续上一次的值 1，变成 2，返回并打印 `2`。
这说明 `count` 的状态被闭包**持续保存**在内存中。

## 三、什么是闭包（Closure）

### 定义
**闭包**是指：一个函数**能够记住并访问它定义时所在的词法作用域（lexical scope）**，即使这个函数在其原始作用域之外被调用。

简单说：**函数 + 函数所引用的外部变量环境 = 闭包。**

### 形成闭包的条件
1. 存在函数嵌套（函数内部定义另一个函数）。
2. 内部函数引用了外部函数的变量。
3. 内部函数被返回（或以其它方式）到外部使用。

本例三点都满足，因此形成了闭包。

### 闭包的核心特性
- **变量不被销毁**：外层函数执行完后，被内部函数引用的变量会一直保留在内存中。
- **状态私有且持久**：`count` 无法从外部直接修改，只能通过 `counter()` 访问；且多次调用之间状态是连续的。
- **每次调用工厂函数会创建独立的闭包**：

```javascript
const c1 = createCounter();
const c2 = createCounter();
console.log(c1()); // 1
console.log(c1()); // 2
console.log(c2()); // 1   ← c2 拥有自己独立的 count，互不影响
```

## 四、闭包的常见用途

1. **数据私有化 / 封装**：模拟「私有变量」，避免全局污染（如本例的 `count`）。
2. **保持状态**：计数器、缓存、记忆化（memoization）。
3. **函数工厂**：根据参数生成定制化的函数。
4. **回调与事件处理**：在异步回调中记住当时的上下文。

```javascript
// 函数工厂示例
function makeAdder(x) {
    return function(y) {
        return x + y; // 记住了 x
    };
}
const add5 = makeAdder(5);
console.log(add5(3)); // 8
```

## 五、注意事项

- **内存占用**：闭包会让被引用的变量常驻内存，滥用可能导致内存无法及时释放（内存泄漏）。用完可将引用置为 `null`。
- **循环中的闭包陷阱**：在 `for` 循环里用 `var` + 闭包容易共享同一个变量，应改用 `let`（块级作用域）：

```javascript
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 0); // 0 1 2（用 let 正确）
}
```

## 六、小结

- 本例通过 `createCounter` 返回一个内部函数，内部函数引用了外层的 `count`，形成闭包。
- 闭包让 `count` **持久保存、外部不可直接访问**，实现了一个有状态的私有计数器。
- 闭包 = **函数 + 它记住的外部作用域**，是 JavaScript 实现封装、保持状态、函数工厂等能力的基础。
