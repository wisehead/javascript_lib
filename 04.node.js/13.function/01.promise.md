# 01.promise.js 逐行解释

```javascript
function readFilePromise(path) {
  return new Promise((resolve, reject) => {
    fs.readFile(path, 'utf8', (err, data) => {
      if (err) reject(err);
      else resolve(data);
    });
  });
}
```

## 逐行说明

### 第 1 行
```javascript
function readFilePromise(path) {
```
定义一个名为 `readFilePromise` 的函数，接收一个参数 `path`（文件路径）。这个函数的作用是把 Node.js 基于回调（callback）的 `fs.readFile` 封装成返回 Promise 的形式，方便使用 `.then()` 或 `async/await`。

### 第 2 行
```javascript
  return new Promise((resolve, reject) => {
```
函数返回一个新的 `Promise` 对象。`Promise` 的构造函数接收一个「执行器函数」（executor），该函数带两个参数：
- `resolve`：调用它表示操作成功，并把结果传出去（Promise 变为 fulfilled 状态）。
- `reject`：调用它表示操作失败，并把错误传出去（Promise 变为 rejected 状态）。

执行器函数会被立即同步执行。

### 第 3 行
```javascript
    fs.readFile(path, 'utf8', (err, data) => {
```
调用 Node.js 文件系统模块的 `fs.readFile` 异步读取文件：
- 第一个参数 `path`：要读取的文件路径。
- 第二个参数 `'utf8'`：编码方式，指定后返回字符串（否则返回 Buffer）。
- 第三个参数是回调函数，遵循 Node.js 的「错误优先」约定，参数为 `(err, data)`。

> 注意：本文件中未看到 `const fs = require('fs')`，实际运行时需要先引入 `fs` 模块。

### 第 4 行
```javascript
      if (err) reject(err);
```
如果读取过程中发生错误（`err` 不为 `null`/`undefined`），调用 `reject(err)`，使 Promise 进入 rejected 状态，把错误对象传递给调用方（可用 `.catch()` 捕获）。

### 第 5 行
```javascript
      else resolve(data);
```
否则（没有错误），调用 `resolve(data)`，使 Promise 进入 fulfilled 状态，把读取到的文件内容 `data` 传递给调用方（可用 `.then()` 接收）。

### 第 6 行
```javascript
    });
```
结束 `fs.readFile` 回调函数与调用。

### 第 7 行
```javascript
  });
```
结束 `Promise` 的执行器函数与 `new Promise(...)` 调用。

### 第 8 行
```javascript
}
```
结束 `readFilePromise` 函数定义。

## 使用示例

```javascript
const fs = require('fs');

// 方式一：.then / .catch
readFilePromise('./demo.txt')
  .then(data => console.log(data))
  .catch(err => console.error('读取失败:', err));

// 方式二：async / await
async function main() {
  try {
    const data = await readFilePromise('./demo.txt');
    console.log(data);
  } catch (err) {
    console.error('读取失败:', err);
  }
}
main();
```

## 核心知识点

- **Promise 封装（Promisify）**：把回调风格的异步 API 转换成 Promise，避免「回调地狱」。
- **错误优先回调**：Node.js 回调约定第一个参数是错误 `err`。
- **状态单向不可逆**：Promise 一旦 `resolve` 或 `reject`，状态便固定，后续再调用无效。
- Node.js 内置的 `util.promisify(fs.readFile)` 可以自动完成同样的封装。
